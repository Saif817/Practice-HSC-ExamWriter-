Exam Instructions

  • Select your subject (or set a custom duration) on the setup screen, then choose any Extra Time or Rest Break provisions before you begin.
  • Copying and pasting only works inside the ExamWriter — content cannot be pasted in from, or copied out to, other applications.
  • Use Start Rest Break to pause the exam clock and start the rest break clock. Select it again to resume the exam.
  • You may add up to 20 pages using the New button.
  • When you are finished, use Export / Print to save your work as a PDF, then select Leave Exam.

Leave Exam?

Your work will not be saved inside the ExamWriter. Make sure you have exported/printed a PDF copy before leaving. This action cannot be undone.
